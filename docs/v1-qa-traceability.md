## Concrete closeout gaps

1. **Applicable v1 acceptance:** no current-source all-four-environment journey/signoff is established here. `docs/STATUS.md` explicitly requires current CPU-runner repeats of T-905–908 and retains native clipboard/owner/opt-out, compositor/portal/GNOME, physical Scroll Lock and autostart as QA. Dated GPU/fallback results must retain their original source/environment boundaries.
2. **Applicable v1 T-604 scope:** `W-session::t604_capture_readback` checks text+HTML offers/readback through `WlMonitor`/`WlTransfer`; it neither sends capture through the daemon/store nor exercises every v1 MIME. `t604_password_hint_skip` asserts the backend event flag; shared daemon sensitive-admission controls are separate evidence. Extend the evidence matrix before claiming the full seg-06 T-604 contract.
3. **Applicable v1 dual-backend evidence:** named `T-605`/`t605` search found no case in `crates/backend-wayland` or `crates/backend-x11`. T-603 pure merge controls and daemon self-write controls do not independently prove simultaneous Xvfb+nested-Wayland integration. Record a missing integration receipt/coverage item; this audit does not infer that implementation is broken or that no differently named scenario exists elsewhere.
4. **Applicable v1 native proof:** Windows `session_acceptance.rs` is `cfg(windows)` and empty on Linux; its documented unavailable-session guard returns success. Xvfb and Sway harnesses document SKIP/early returns when facilities are absent. Gate exit zero without non-skip evidence cannot close those OS contracts. Windows harness deliberately avoids `paste_to`; native paste/target/UAC therefore needs its separate fixture/manual evidence.
5. **Applicable source/evidence follow-up:** age/hourly-retention, DB compact, full local diagnostics/open-folder, complete MIME fidelity, plugin reservation consistency and kill-mid-write blob recovery were not established in this bounded audit. These are explicit evidence gaps, not findings that the functions are absent. Existing cases should be traced before adding tests.
6. **Index ambiguity:** older `ui_acceptance.rs` names use `t901_*` for strings, `t902_*` for search and `t903_*` for keymap, while seg-09 assigns T-901 search, T-902 keymap, T-903 placement, T-910 strings. `ui_v1_acceptance.rs` carries correctly named counterparts. Use case/assertion semantics and paths, not numeric grep counts, for receipts.
7. **Separate cross-cutting obligations:** T-1103 24h soak, memory/CPU/search budgets, T-1105 parser/macro fuzzing, coverage-floor enforcement, T-1106 cross-version restore matrix, T-1117 release evidence-bundle audit and T-1101/1201 artifact installation remain separate unproved obligations in this report. No full-suite count substitutes for them. v2 macro/JS/plugin/locale tests and v3 sync/shared DB/Jumplist features are not missing v1 implementation.
