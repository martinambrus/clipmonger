# Clipmonger user guide

These pages explain how to install, set up and use Clipmonger. For a short
overview of what it does, see the [project README](../../README.md).

## Getting started

Install Clipmonger and get it running on your system:

- [Windows](getting-started-windows.md)
- [macOS](getting-started-macos.md)
- [Linux](getting-started-linux.md) (X11, Wayland, GNOME, KDE Plasma, Xfce,
  Sway, Hyprland, COSMIC)
